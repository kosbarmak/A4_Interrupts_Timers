**Sociotechnical Question**

"The design of electronic locks made certain assumptions about how it is used - what assumptions were made about the users? 
What types of users are better supported by this device, and which types of users were disproportionately impacted by this
type of device."

Buttons and locks assume that the user has the physical ability to press buttons and manipulate physical object. These kinds
of devices do not account for users with disabilities or who otherwise cannot interface with the device in this tactile way.
Our implementation also lacks certain features - such as disabling wether the LED turns off. In our case, we could simply 
take the LED off from the circuit, but that is not an accessible format for similar reasons as stated previously.
